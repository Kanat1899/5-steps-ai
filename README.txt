5 STEPS AI — 2-сыныпта орыс тілін оқытуға арналған платформа
Платформа обучения русскому языку во 2 классе
=====================================================================

ІШІНДЕ НЕ БАР / СОДЕРЖИМОЕ
  5_steps_kk.html      — қазақша интерфейс. Екі рет басып, браузерде ашыңыз.
  5_steps_ru.html      — русский интерфейс. Откройте двойным щелчком.
  netlify_site/        — сайт үшін (Netlify): index.html (қаз.), ru.html (рус.),
                         netlify/functions/tts.js — тірі онлайн-дауыс функциясы.
  sounds_preview.wav   — дыбыстар үлгісі: дұрыс → қате → жеңіс.
  TEST_REPORT.txt      — тестілеу есебі / отчёт о тестировании.

Екі нұсқада да жоғарғы оң жақта «Қазақша | Русский» ауыстырғышы бар.
Қазақшаға тек интерфейс аударылған. Оқу материалы — сөздер, сөйлемдер,
сұрақтар, тақырып атаулары — әрқашан орысша (бұл орыс тілін оқыту бағдарламасы).
Переведён только интерфейс; учебный материал всегда на русском.

МҮМКІНДІКТЕРІ / ВОЗМОЖНОСТИ
  • 8 бөлім, 32 тақырып, 5 қадам: КӨР · ТЫҢДА · ОЙНА · ҚҰРАСТЫР · ҰСЫН
  • A / B / C жеке бағыттары: карточка, жұп және нұсқа саны әр түрлі
  • Қаріп 18px, қарапайым анимация, жұмсақ дыбыстар (ақырын / қаттырақ / өшірулі)
  • Тапсырма түрлері: сөзді тап, артық сөз, бірінші әріп, буын саны, тыңдау,
    «Сөзді құрастыр» ойыны, сөйлем құрастыру (еркін сөз тәртібі), жауап жазу
  • Жауап орысша екені тексеріледі; «↩ Соңғысын алып тастау», «🧹 Қайта бастау»
  • Үлгерім мониторингі, CSV-ге жүктеу (Excel-де дұрыс ашылады)
  • Телефонда да толық жұмыс істейді; интернетсіз де жұмыс істейді

ТІРІ ДАУЫС / ЖИВОЙ ГОЛОС («Тыңда» / «Услышь»)
  Бағдарлама ең табиғи дауысты өзі таңдайды. Реті:
  1) Онлайн-дауыс (OpenAI, ең тірі) — сайт Netlify-де және кілт қосылған болса.
  2) Құрылғының ең табиғи орыс дауысы.

  ✔ ТЕГІН ЖОЛ: бетті Microsoft Edge браузерінде ашыңыз (интернет қосулы болсын).
    Edge-де тегін нейрон-дауыстар бар: Microsoft Svetlana / Dmitry (Natural).
    Бағдарлама оларды өзі таңдайды. Құрылғыда бірнеше орыс дауысы болса,
    «Тыңда» қадамының астында «Құрылғы дауысы» тізімі шығады — ★ белгісі
    бар дауыс ең табиғи. Таңдау есте сақталады.
  ✔ ЕҢ ТІРІ ДАУЫС: Netlify + OpenAI (ақылы, кілт керек):
    1. app.netlify.com сайтына кіріп, netlify_site папкасын сүйреп апарыңыз.
    2. Site configuration → Environment variables → OPENAI_API_KEY = сіздің кілтіңіз.
    3. Deploys → Trigger deploy.
    4. Functions бөлімінде «tts» шыққанын тексеріңіз. Шықпаса — сайтты GitHub
       арқылы қосыңыз немесе Netlify CLI: netlify deploy --prod
    Дауыс: marin (ең табиғи). Өзгерту: TTS_VOICE = coral / nova / shimmer / sage.
    Бір сөз бір рет қана жүктеледі, қайта тыңдау тегін.

  Құрылғыда орыс дауысы мүлде жоқ болса (Windows):
    Параметры → Время и язык → Речь → Добавить голоса → Русский.
